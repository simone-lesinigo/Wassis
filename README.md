# Wassis

**WA**ve function collapse for **S**oftware **S**ystem v**IS**ualization

is a research tool developed as part of my Master's thesis in Informatics, in the context of the double degree program between Università della Svizzera italiana (USI) and Università degli Studi di Milano-Bicocca.

It combines **Multidimensional Scaling (MDS)** and **Wave Function Collapse (WFC)** to automatically generate layouts for software systems, depicting their classes and relationships.
