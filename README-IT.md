# Wassis

**WA**ve function collapse for **S**oftware **S**ystem v**IS**ualization

Wassis è uno strumento di ricerca sviluppato nell'ambito della mia tesi di laurea magistrale in Informatica, all'interno del programma di doppia laurea tra Università della Svizzera italiana (USI) e Università degli Studi di Milano-Bicocca.

Combina **Multidimensional Scaling (MDS)** e **Wave Function Collapse (WFC)** per generare automaticamente layout di sistemi software, rappresentandone le classi e le relazioni.

## 📚 Ricerca

Il progetto è accompagnato da una tesi di laurea magistrale e da un paper scientifico sottoposto a peer review e presentato a [VISSOFT 2026](https://vissoft.io/2026/index.html).
